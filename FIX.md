**Цель:** подготовить безопасную, воспроизводимую англоязычную demo-версию и доказательные материалы для отзыва профессора в США.

Основание: [аудит и доказательства](docs/audits/2026-09-20/REPORT.md), последующие предложения по развитию проекта. Аудит относится к commit `ae6d3463144a6cf0ebcc6ccbba9f0cd4ec8bd9da`; перед исполнением проверить актуальный код. Этот файл — текущая очередь работ. Исторический отчёт сохранять без переписывания результатов.

## Правила исполнения

- Выполнять этапы A → B → C → D, учитывая зависимости задач.
- Отмечать задачу `[x]` только после выполнения её критериев приёмки. Рядом записывать commit, команду проверки и результат или ссылку на доказательство.
- Не считать сборку доказательством работающего пользовательского сценария, а unit-тест с заглушкой — проверкой PostgreSQL или браузерного расширения.
- Для гипотез сначала воспроизвести проблему. Если она не подтверждается, записать проверенные условия и результат вместо ненужного изменения кода.
- Не сбрасывать существующую БД и не запускать разрушительный seed. Интеграционные тесты проводить на изолированных данных.
- Не публиковать секреты, реальные URL пользователей и персональные данные в логах, fixtures или отчётах.
- Различать «инструмент реализован», «эксперимент проведён» и «эффективность подтверждена». Синтетические результаты не выдавать за исследование с участниками.
- Создание этого плана не означает публикацию сайта, рассылку профессорам, набор участников или ротацию действующих credentials. Эти действия выполнять в рамках отдельно согласованного конкретного назначения.
