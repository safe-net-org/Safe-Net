# Safe-Net: запись демонстрации

Автор: Volkov Artem Aleksandrovich. Длительность: 60–90 секунд. Язык интерфейса: English.

## Перед записью

Открой локальный проект на http://localhost:3000. Войди в демонстрационный аккаунт заранее. Выбери светлую тему и English. Подготовь отдельное окно браузера; закрой лишние вкладки и уведомления. Пароли, письма и настройки аккаунта в запись не включай.

Записывай окно браузера в Screen Studio. Для чёткого текста исходная запись должна быть не меньше 2560×1440. Экспорт: **2560×1440, 30 fps, MP4/H.264**. Если окно меньше, экспорт в 1440p лишь увеличит картинку: лучше записать большое окно на Retina-дисплее.

## Сцены

| Время | Что показать | Короткий английский комментарий |
|---|---|---|
| 0–8 с | Главная страница, затем Start Learning | “I'm Volkov Artem Aleksandrovich. This is Safe-Net, my cybersecurity learning project.” |
| 8–20 с | Каталог, VPN and Encryption, затем VPN Basics | “The app combines short lessons with practice tasks and saves progress to the learner's account.” |
| 20–38 с | Задание What Your ISP Sees: выбрать ответ, Check answer, задержаться на объяснении | “The server grades the answer and returns an explanation. Repeating a completed task does not add XP.” |
| 38–65 с | /guard, Try the live scanner, пример micros0ft-alerts.com/login, Scan | “Guard checks the URL locally. It flags the altered brand spelling and shows the signals behind the warning.” |
| 65–80 с | My Certificates → сертификат VPN and Encryption | “Course completion creates a certificate inside the platform. This account is a local demonstration.” |
| 80–90 с | Завершить на главной или Guard | “My next step is to evaluate the detector and study whether learners recognise unfamiliar phishing cues.” |

Адрес для Guard вставляй **только в поле сканера**, не в адресную строку браузера. Можно использовать готовые примеры под полем. Не запрашивай модель: для этой демонстрации достаточно локального результата.

## Лёгкий монтаж

- Убери паузы загрузки, случайные клики и возвращение к уже показанному экрану.
- Оставляй объяснения на экране на 3–4 секунды.
- Используй спокойное приближение к заданию и к списку сигналов Guard; двух-трёх приближений на весь ролик достаточно.
- Фон тёмно-синий, небольшие поля вокруг окна, без ярких переходов. Заголовки: “Learn”, “Practise”, “Explain”, “Track progress”.
- Речь можно записать отдельно. Музыка необязательна; при наличии она должна быть заметно тише голоса.
- В начале или конце добавь “Safe-Net · Volkov Artem Aleksandrovich · Local prototype”.

Пришли исходную запись без сильного сжатия. Тогда можно будет подрезать паузы, добавить титры и собрать финальную версию для профессора. Текущая презентация готовится отдельно; видео пока не записано.
